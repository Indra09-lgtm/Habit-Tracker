# Habit Tracker (Gentle Nudges Edition)

A simple command-line habit tracker that avoids the harsh "broken streak" 
approach used by most habit apps. Instead of punishing a missed day, it 
shows a supportive message based on your overall weekly progress.

## Why this is different

Most habit trackers use streaks — if you miss one day, your progress 
resets to zero, which can feel discouraging. This tracker instead looks 
at your overall consistency (e.g. "5 out of 7 days") and responds with 
encouragement, not judgment, even on a rough week.

## Features

- Add multiple habits
- Mark days as completed or missed
- See a weekly completion percentage for each habit
- Get a supportive message based on your progress
- Data is saved automatically and reloaded next time you run it

## How to run it

1. Make sure Python is installed on your computer.
2. Run the program from your terminal:python main.py
3. Enter a habit name, then enter dates you completed or missed it.
4. Type `done` to move to the next step or finish.
5. See your summary and a supportive message for each habit.
